Professor e pesquisador em Computação na Universidade Federal de Ciência e Inovação de Minas Gerais (UFCI-MG), Campus Varginha.

Doutorando em Engenharia da Informação (UFABC), mestre em Engenharia Mineral (Poli-USP), engenheiro de computação (UNIVESP), geofísico (IAG-USP) e pedagogo.

## Sobre o site

Portal acadêmico bilíngue (português e inglês), dedicado à divulgação de atividades de ensino, pesquisa, extensão e produção científica.

- **Ensino:** disciplinas, slides, notebooks e materiais didáticos.
- **Pesquisa e extensão:** projetos acadêmicos e iniciativas de interação com a sociedade.
- **Publicações:** artigos, trabalhos científicos e apresentações.
- **Sobre:** trajetória acadêmica, formação, competências e perfis profissionais.

## Tecnologias

React, TypeScript, Sass e tsParticles. A aplicação possui interface responsiva, temas claro e escuro e hospedagem no Netlify.

## Execução local

```bash
npm ci
npm start
```

Para gerar a versão de produção:

```bash
npm run build
```
